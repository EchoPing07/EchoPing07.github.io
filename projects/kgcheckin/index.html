kgcheckin：酷狗概念版 VIP 每日自动签到

基于青龙面板的酷狗概念版 VIP 自动签到工具，支持多账号、Token 自动续期、日志脱敏和通知推送。

酷狗概念版每天可以免费领取 VIP，但需要手动打开 App 听歌、看广告才能完成签到。kgcheckin 把这套流程脚本化，挂到青龙面板上每天自动跑，从此不用再惦记这件事。

为什么做这个#

酷狗概念版的 VIP 领取需要每天手动操作：打开 App → 听歌 → 看广告。一天不操作就断签，多账号更是折磨。作为一个青龙面板用户，把这件事自动化是最自然的选择。

核心特性#

  • 每日自动签到：自动完成听歌任务与广告任务，无需手动打开 App。
  • 多账号支持：一份环境变量配置多个账号（@ 分隔），一次任务全部签到。
  • Token 自动续期（可选）：配置青龙 OpenAPI 凭证后，每周日自动刷新 token 并回写环境变量，长期免维护。未配置则跳过刷新，避免 token 提前失效。
  • 日志脱敏：昵称、用户 ID 等敏感信息在日志中自动打码（如 张**三、204***16），token 显示为 [REDACTED]。
  • 通知推送：复用青龙内置的 sendNotify，签到结果直达你已配置的通知渠道（Server 酱、Telegram、企业微信等）。
  • 零 HTTP 服务：脚本以函数调用方式直接请求接口，不启动任何常驻服务，内存占用极低。

青龙定时任务触发（每天凌晨 1:10）
  → 读取 KUGOU_CK 环境变量，解析出所有账号
  → 逐账号验证 token 有效性
  → 调用听歌接口领取 VIP
  → 调用广告接口领取 VIP（多次）
  → 查询 VIP 到期时间
  → 汇总结果，发送通知
  → （每周日）刷新 token → 通过 OpenAPI 写回环境变量 → 校验

API 签名和加密模块基于 MakcRe/KuGouMusicApi，包含 MD5、AES、RSA 等酷狗接口所需的加解密逻辑。

Token 续期机制#

酷狗的 token 会过期，过期后必须重新抓包。配置自动续期后，脚本每周日运行时会自动刷新 token 并通过青龙 OpenAPI 写回 KUGOU_CK 环境变量。

写回后会再次读取进行校验。如果校验失败（权限不足、网络抖动等），脚本会通过通知渠道把新 token 推送给你，方便手动更新，避免账号断签。

不配置 OpenAPI 凭证时，脚本不会刷新 token，当前 token 在有效期内可以一直正常使用。

部署与使用#

整体流程：在青龙面板添加仓库订阅 → 安装 axios 依赖 → 抓包获取 userid 和 token → 配置 KUGOU_CK 环境变量 → 创建定时任务。

抓包工具推荐：iOS 用 Stream 或 Shadowrocket，Android 用 HttpCanary 或 Packet Capture。过滤 gateway.kugou.com 域名，从请求的 Cookie 或 Header 中提取 userid 和 token。

详细的分步部署指南、环境变量说明、常见问题排查都在仓库 README 中。

常见问题速览#

  • error_code 130012 / 20028 / 30002：这些是"今日已完成"的正常状态码，不是错误。
  • Cannot find module ‘axios’：依赖没装好，回青龙「依赖管理」重新安装。
  • 多账号只有第一个成功：检查 KUGOU_CK 格式，账号内部用 #，账号之间用 @，不要有多余空格。
